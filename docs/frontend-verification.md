# Проверка клиента React/Vite

19.11.2026: npm ci — 66 пакетов проверено, известных уязвимостей не обнаружено; npm run build — успешно, Vite 7.3.8, 34 модуля.

Проверена готовая сборка в Chromium с тестовыми ответами API: каталог, поиск, Canvas и скачивание PNG, вход с Bearer-токеном, сохранение персонажа, создание публикации, лайк, ошибка валидации при модерации, список аккаунтов, выход. На ширине 390px горизонтального переполнения нет. Ошибок JavaScript не обнаружено.

Эта проверка изолирует поведение клиента; она не заменяет интеграционный прогон с рабочим API. Серверный набор проверок описан отдельно в kp10-verification.md.

Исходники клиента находятся в client/react, готовая сборка — в client. Для сборки используются React, react-dom, Vite и @vitejs/plugin-react; взаимодействие с Laravel выполняется через fetch.
